# simulator-web

Frontend scaffold for IoT Simulator (Phase 3A).

## Stack

- React 18 + TypeScript + Vite
- React Router v6
- TanStack Query
- Zustand

## Start (when npm is available)

```bash
npm install
npm run dev
```

Default expected backend:

- API: `http://localhost:8090`
- WS: `ws://localhost:8090`

Environment template:

- `.env.example`
