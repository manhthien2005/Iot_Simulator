Phòng nghiên cứu té ngã

Inject các kịch bản té ngã, theo dõi quy trình AI đánh giá (pre-trigger → model API → verdict), quan sát biến thiên sinh hiệu sau té ngã và xác minh BE escalation tương ứng. Mọi số liệu đều derive từ BE — không invent dữ liệu.

ⓘ
Lưu ý độ trễ trong giả lập: Trên simulator, inject_event chạy đồng bộ tới Model API (port 8001) và trả verdict trong ~50–200ms. Trên mobile thực, độ trễ end-to-end là 1–3s (MQTT → BE buffer → model API → push notif). Pre-inject confirm dialog đã được loại bỏ (gây delay không tồn tại trong production flow). Hủy SOS bằng nút "Tôi ổn" giữ nguyên vì mobile production cũng có nút này.
